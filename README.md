# DevOps Capstone Project: Customer Accounts Microservice

[![CI Build](https://github.com/Manasvidhawale/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/Manasvidhawale/devops-capstone-project/actions/workflows/ci-build.yaml)

A production-ready Customer Accounts microservice demonstrating complete DevOps lifecycle practices:
- Agile Project Planning with GitHub Issues & Projects (User stories, Sprints, Kanban)
- RESTful Microservice with Flask and SQLAlchemy (TDD & BDD testing)
- Security hardening with Flask-Talisman headers and CORS policies
- Containerization with Docker and multi-stage builds
- Automated Continuous Integration with GitHub Actions
- Continuous Deployment to Kubernetes using OpenShift and Tekton Pipelines
